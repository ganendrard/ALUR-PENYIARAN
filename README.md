# 📡 ALUR PENYIARAN

> Dokumentasi visual dan teknis mengenai proses, workflow, serta implementasi alur penyiaran (broadcast workflow).

![Banner](./Alur%20Penyiaran.png)

## 📖 Tentang Proyek

Proyek ini dibuat untuk mendokumentasikan dan memvisualisasikan proses penyiaran secara terstruktur, mulai dari tahap perencanaan konten hingga distribusi siaran.

Dokumentasi disajikan dalam berbagai format visual seperti:

- PNG Diagram
- PDF Dokumentasi
- Microsoft Visio (VSDX)
- SVG Diagram
- Dokumentasi Implementasi
- Halaman Web Interaktif

Tujuan utama proyek ini adalah membantu memahami alur kerja penyiaran secara lebih mudah, sistematis, dan terdokumentasi dengan baik.

---

## 🎯 Tujuan

- Memetakan proses penyiaran secara end-to-end.
- Menyediakan referensi visual yang mudah dipahami.
- Mendukung dokumentasi akademik maupun profesional.
- Menjadi dasar pengembangan sistem manajemen penyiaran.

## 🚀 Cara Menggunakan

### Clone Repository

```bash

```

### Masuk ke Folder

```bash
cd ALUR-PENYIARAN
```

### Buka Dokumentasi

- PDF → buka menggunakan PDF Reader
- PNG/SVG → buka melalui browser atau image viewer
- VSDX → buka menggunakan Microsoft Visio
